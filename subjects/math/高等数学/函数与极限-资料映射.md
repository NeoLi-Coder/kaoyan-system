## 一、知识范围

本单元按数学知识点组织，不按老师或文件夹重复拆分：

1. 函数概念与常见函数；
2. 函数性质、反函数与复合函数；
3. 数列极限的概念、性质和存在准则；
4. 函数极限、左右极限和基本计算；
5. 连续性、间断点和闭区间连续函数性质。

## 三、统一内化格式

每个知识点只保留一份主体内容，后续按以下字段补充：

| 字段 | 要回答的问题 |
|---|---|
| 定义与对象 | 研究的对象是什么，如何准确表述？ |
| 核心性质 | 有哪些结论，成立需要什么条件？ |
| 方法与题型 | 题目出现什么信号时，考虑什么方法？ |
| 推导或理由 | 公式、性质为什么成立？ |
| 易错边界 | 哪些相似说法容易混淆，哪些条件不能省略？ |
| 主动输出 | 不看资料能否复述、画图或写出步骤？ |
| 题目验证 | 用哪些基础题和常规题检验？ |
| 来源依据 | 具体来自哪份讲义、课程或题目？ |

## 四、去重与冲突规则

- 同一知识点的不同课程目录只登记为多个来源，不复制成多份知识笔记。
- 当前主线默认使用武忠祥资料；其他数学课程只有在明确出现知识缺口时再比较。
- 不同资料说法不一致时，保留“差异与待核验”记录，不直接覆盖原结论。
- 课程目录、计划和本文件都不能证明知识已经掌握；掌握等级只能根据主动输出和题目记录判断。
