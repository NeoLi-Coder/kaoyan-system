# 考研各科第一轮复习资料选择与使用方案 V1.0

> 适用周期：2026年8月—2026年12月  
> 适用目标：电子科技大学计算机专业硕士初试，第一轮复习  
> 适用科目：数学一、英语一、思想政治理论、408计算机学科专业基础  
> 文档定位：确定各科唯一主线资料、补充资料、启用条件和停止条件，防止资料过载与重复听课。

---

## 一、总原则

### 1. 老师和课程只是知识输入来源

第一轮学习进度按以下结果判断：

```text
知识节点已建立
→ 核心概念能够解释
→ 基础题和常规题能够独立完成
→ 错误能够归因并修正
→ 周测达到阶段要求
```

不得使用“看完多少课程”或“完成多少视频”作为主要进度指标。

### 2. 每个模块只保留一条主线

同一模块不得同时完整学习两套课程。备用课程只在以下情况启用：

- 主线课程对应知识点连续两次仍无法理解；
- 主线课程缺少具体考点；
- 需要另一种讲解方式解决单点困难；
- 错题暴露出明确前置知识缺口。

备用课程启用后，只学习对应知识点，不顺序观看整套课程。

### 3. 资料使用顺序

```text
明确知识节点
→ 阅读主讲义或教材
→ 观看对应课程
→ 独立复做例题
→ 完成基础练习
→ 整理错误
→ 章节检测
```

数学、408必须保证练习时间高于课程时间；英语必须把词汇、句法放入真题语境；政治必须以选择题验证理解。

### 4. 资料停止条件

出现以下任一情况，应暂停继续增加资料：

- 同类资料已经存在一套完整主线；
- 当前问题属于练习不足，而非讲解不足；
- 已能独立完成对应基础题；
- 新资料与已有资料内容高度重复；
- 新资料会挤占做题、复盘或真题训练时间。

## 三、数学一资料方案

### 3.1 高等数学

#### 主线资料

```text
01.【2027考研数学】武忠祥有道领学班
```

配套书目：

- 27武忠祥《高数基础篇》；
- 2027考研数学《基础过关·基础练习册》；
- 2027考研数学《常用公式手册》；
- 27武忠祥《高数基础篇·严选题》；
- 《数一660题》。

#### 第一轮使用方式

```text
《高数基础篇》确定知识结构
→ 武忠祥对应课程解决概念和方法
→ 《基础练习册》完成基础训练
→ 错题回查讲义或解析
→ 章节测试验收
```

#### 各资料定位

| 资料 | 定位 | 第一轮使用规则 |
|---|---|---|
| 《高数基础篇》 | 主讲义 | 每章先看结构、定义、例题和题型总结 |
| 武忠祥基础课程 | 主讲解 | 只看当前知识节点对应内容 |
| 《基础练习册》 | 主习题册 | 承担第一轮主要题量 |
| 《常用公式手册》 | 查询资料 | 查公式、条件和结论，不作为背诵主线 |
| 《严选题》 | 第二层训练 | 基础题正确率达到约70%后选做 |
| 《数一660题》 | 选择填空检测 | 章节完成后使用，不与基础练习册同步全刷 |
| 零基础入门课 | 缺口补课 | 只补函数、极限、导数、积分等明确缺口 |

#### 不执行的方式

- 不完整观看所有零基础课程；
- 不同时完整刷基础练习册、严选题和660题；
- 不因视频未看完而延迟做题；
- 不把课堂笔记直接当作自己的理解结果。

### 3.2 线性代数

#### 主线课程路径

```text
14.【2027考研数学】李永乐金榜SVIP班
└─ 2027考研数学金榜高分VIP班 李永乐
   └─ 04.大纲考点精讲
      └─ 02.线性代数知识精讲
```

该部分按以下模块拆分：

- 行列式；
- 矩阵及其运算；
- 线性方程组；
- 向量及线性关系；
- 特征值与特征向量；
- 二次型与正定。

#### 选择该课程的原因

课程颗粒度较细，便于将每天任务拆成单个知识节点；相比13个超长视频的“大纲基础知识精讲”，更适合当前基础薄弱、需要分步验证的学习方式。

#### 备用课程路径

```text
26.【2027考研数学】李永乐线代全程班
└─ 02.线性代数0基础入门（带字幕版）
```

只在以下内容完全无法进入时调用对应单节：

- 矩阵乘法和初等变换；
- 矩阵的秩；
- 线性表示和线性相关；
- 基础解系；
- 特征值与相似对角化；
- 二次型标准化。

#### 章节练习

```text
26.【2027考研数学】李永乐线代全程班
└─ 05.660线代逐章精选题带练
```

使用规则：

1. 先独立完成题目；
2. 标记不会、做错和方法不稳定的题；
3. 只看对应讲解；
4. 重新独立完成一次。

#### 跳过项

- 两套重复的“线性代数0基础入门”不得同时观看；
- 第一轮不进入强化突破和选填技巧；
- 不顺序观看660题带练代替独立做题。

→ 概率必刷基础题

基础阶段需要覆盖：

## 四、英语一资料方案

### 4.1 词汇、语法与长难句

#### 主线资料

```text
03.【2027考研英语】田静启航全程班
```

重点使用：

- 词汇学习方法；
- 基础词和高频词资料；
- 真题词汇和熟词僻义；
- 零基础语法；
- 核心语法；
- 长难句分析；
- 真题句子带练。

#### 学习流程

```text
词汇进入真题语境
→ 提取句子主干
→ 判断从句关系
→ 识别修饰成分
→ 理解逻辑关系
→ 形成自然中文
→ 口头复述或造句
```

#### 单词课程使用规则

单词视频不作为每日主线，只在以下情况调用：

- 词根词缀关系不清；
- 熟词僻义反复出错；
- 单词在真题中无法识别；
- 需要建立核心搭配或语块。

每日词汇必须通过真题句子、搭配、造句或复述验证，禁止连续投入大量时间只看单词视频。

### 4.2 阅读理解

#### 主线课程路径

```text
23.【2027考研英语】哔哩唐迟全程班
├─ 09 阅读思维构建与应用
├─ 16 阅读方法拔高
└─ 11 阅读真题逐篇代刷英语一
```

#### 第一轮执行顺序

```text
阅读方法基础
→ 独立完成2005—2009年真题
→ 复盘文章结构和题型
→ 阅读方法拔高
→ 2010年后真题逐篇训练
```

#### 每篇阅读的标准流程

1. 限时独立作答；
2. 标记不确定题目；
3. 定位原文证据；
4. 分析正确选项与干扰项；
5. 拆解关键长难句；
6. 整理生词、熟词僻义和搭配；
7. 再看对应课程；
8. 次日回忆文章逻辑和错题原因。

#### 视频启用条件

`11 阅读真题逐篇代刷英语一`只能在独立作答和证据定位后观看。不得顺序追完所有解析视频。

#### 跳过项

```text
13 阅读真题文章精读
```

该部分与逐篇代刷内容大量重复，默认不进入主线。

#### 补充课程

```text
18.【2027考研英语】唐迟有道领学班
└─ 03.巩固突破
   └─ 03 阅读
      └─ 01 05&07年经典阅读精讲 唐迟
```

仅在2005年、2007年阅读训练后仍无法建立文章结构和题型方法时启用。

## 六、408资料方案

### 6.1 唯一主线

```text
04.【2027考研计算机】王道全程班
＋
2027王道四本复习指导
＋
书内章节题
＋
2009—2026年408真题
```

四本复习指导：

- 数据结构；
- 计算机组成原理；
- 操作系统；
- 计算机网络。

### 6.2 标准学习流程

```text
阅读王道对应小节
→ 建立章节框架
→ 观看对应基础课程
→ 闭卷复述机制或执行过程
→ 独立完成章节题
→ 错题对应讲解
→ 周末章节测试
```

### 6.3 课程使用规则

- 基础课程按知识节点观看；
- 单次连续视频学习不超过40分钟；
- 习题讲解必须在独立做题后观看；
- 不完整观看C语言入门课程；
- 只补指针、数组、结构体、内存布局、字符串和链表代码等明确缺口。

### 6.4 其他机构课程的启用条件

高途、研途、研芝士、零壹、BOK等课程不作为并行主线。只有在以下情况启用单点讲解：

- 同一知识点连续两次仍不能解释；
- 王道讲解缺少关键推导；
- 计算题无法理解公式来源；
- 算法执行过程无法独立模拟；
- 选择题边界反复混淆。

每次补充课程只解决一个明确问题，完成后立即返回王道主线。

## 七、每日资料调用规则

每日计划不直接写“看完某课程第几节”，统一写成四个字段：

| 字段 | 内容 |
|---|---|
| 知识节点 | 今天必须建立的概念、机制或题型 |
| 输入资料 | 对应讲义、教材和课程位置 |
| 主动输出 | 复述、推导、造句、画流程或做题 |
| 完成标准 | 正确率、可解释程度和复测要求 |

示例：

```text
知识节点：等价无穷小的使用条件和边界
输入资料：武忠祥《高数基础篇》对应小节＋课程
主动输出：独立说明3种不能直接替换的情况
题目验证：完成10道基础题
完成标准：正确率不低于70%，错题能够说明错误原因
```

## 八、资料调整规则

### 8.1 允许更换资料的情况

- 主线资料连续3个学习单元均无法理解；
- 课程与教材严重不匹配；
- 资料缺少考试大纲中的重要内容；
- 实际学习记录证明当前资料明显降低效率；
- 2027正式考试大纲发生明确调整。

### 8.2 不允许更换资料的情况

- 第一次接触感觉困难；
- 做题错误率暂时较高；
- 看到其他老师口碑更好；
- 新资料讲得更详细但内容重复；
- 因畏难希望重新从零开始；
- 当前问题本质上是练习和复盘不足。

资料调整必须依据学习记录、正确率、错误类型和阶段测试结果，不依据短期感受。

## 十、执行结论

从本方案生效起，不再继续围绕老师和课程反复选资料。所有科目统一执行：

```text
知识节点
→ 主线资料输入
→ 主动理解与输出
→ 独立做题
→ 错题回查
→ 周测验收
```

第一轮目标是形成完整知识主干、掌握基础和常规题、建立错误反馈体系，不要求看完所有课程，也不要求刷完所有题库。
