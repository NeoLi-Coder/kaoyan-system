# 考研长期执行机制与心理建设_V1.0

## 一、制定目的

本机制用于保证2026年电子科技大学计算机专业硕士备考过程中，避免过去复习中出现的三分钟热度、阶段性冲刺、长期中断等问题。

核心原则：

> 不依赖短期激情，坚持依靠可执行系统。

目标：

-   2026年12月31日前完成数学一、英语一、408第一轮主干复习。
-   建立知识体系、基础题和常规题能力、错题反馈体系。
-   通过持续反馈调整学习方案。

------------------------------------------------------------------------

## 二、每日学习执行机制

每日任务由整体计划拆解形成。

任务标准：

-   100%：当天计划目标。
-   60%：最低完成线。
-   80%～100%：正常稳定完成范围。

规则：

1.  每天优先保证最低完成线。
2.  状态良好时可以超额完成，但不能透支后续学习状态。
3.  不允许通过连续爆发学习制造短期满足感，导致后续下降。

------------------------------------------------------------------------

## 三、任务延期处理机制

当日未完成任务：

实际完成情况 → 分析原因 → 判断影响 → 制定补救方案 → 调整后续计划

原因分类：

-   工作导致时间不足。
-   知识难度超过预期。
-   学习方法存在问题。
-   畏难导致回避。
-   时间规划不合理。

延期不能简单累积到未来，而需要明确：

-   为什么没有完成。
-   是否需要调整任务量。
-   是否需要补充前置知识。
-   如何避免重复发生。

------------------------------------------------------------------------

## 四、学习效果评价机制

学习效果不以以下指标作为主要标准：

-   学习时间。
-   视频观看数量。
-   完成章节数量。

真正评价标准：

知识输入 → 主动理解 → 独立输出 → 题目验证 → 错误反馈

每个知识点需要关注：

-   是否理解核心概念。
-   是否知道适用条件。
-   是否能够解决基础题。
-   是否能够识别题型。
-   是否能够总结错误原因。

------------------------------------------------------------------------

## 五、每日学习反馈

每日学习结束后同步：

-   学习内容。
-   实际用时。
-   完成任务比例。
-   题量和正确率。
-   遇到的问题。
-   当前状态。

根据反馈调整：

实际完成情况 → 掌握检测 → 错误分析 → 调整未来任务

------------------------------------------------------------------------

## 六、每周复盘机制

每周末进行一次集中复盘。

检查：

1.  本周计划完成率。
2.  知识掌握程度。
3.  题目应用能力。
4.  错误类型。
5.  时间投入是否合理。
6.  下周任务是否需要调整。

复盘重点：

发现系统问题，而不是单纯评价努力程度。

------------------------------------------------------------------------

## 七、心理建设原则

### 1. 不追求每天完美

备考周期很长，偶尔低效是正常情况。

关键：

-   不让一天失败变成一周失败。
-   不让一次延期变成长期放弃。

### 2. 用系统代替情绪

学习状态会波动：

-   有动力时执行计划。
-   没动力时执行最低完成线。

坚持来自稳定执行，而不是每天充满斗志。

### 3. 关注长期累计

目标不是证明自己某一天很努力。

目标是：

每天完成一点， 每周持续推进， 每月形成积累， 最终达到考试要求。

------------------------------------------------------------------------

## 八、最终执行标准

第一轮复习结束时，不要求所有课程全部看完。

要求：

-   主干知识体系完整。
-   核心概念能够解释。
-   基础题和常规题能够处理。
-   形成错题和反馈体系。
-   明确后续强化方向。

本机制作为考研复习长期执行规则，根据实际学习情况持续迭代。
