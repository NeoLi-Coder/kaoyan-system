# 考研主动学习与知识体系建设规范 V2.0

## 一、核心目标

当前学习模式同时服务于：

1. **知识体系**：明确知识点所属科目、章节、前后依赖和考试位置。
2. **解题能力**：识别题型、选择方法、独立完成基础题和常规题，并解释步骤依据。
3. **考试能力**：依据考研大纲、真题规律和目标分数，稳定获取基础题与中档题分数。

第一轮复习按以下结果推进：

```text
完整走通知识地图
→ 理解核心概念和基本机制
→ 掌握基础方法
→ 完成章节基础题验证
→ 建立后续强化所需的知识定位能力
```

第一轮不追求解决所有综合难题，也不以课程观看数量作为完成标准。

## 二、总体学习原则

成熟讲义或复习指导的目录负责提供知识地图，学习按目录逐章、逐节推进。

```text
讲义目录确定范围和顺序
→ 用户自主阅读建立初步认识
→ GPT 对话教学负责检查、纠错和深化
→ 章节题转化为解题能力
→ 错题反馈修正知识体系
```

课程视频不作为每日学习主线。只有自主阅读和对话讲解后仍无法理解时，才按具体知识点定向观看；观看后必须回到讲义、对话或题目验证。

禁止没有知识地图地随机抛题，也禁止连续听课数小时后用“听完”代替独立理解和做题。

## 三、第一轮知识地图

### 数学一

- 高等数学以 2027 武忠祥《高数基础篇》目录为知识地图，共十二章：函数极限连续、导数与微分、中值定理及导数应用、不定积分、定积分与反常积分、定积分应用、微分方程、多元函数微分学、二重积分、无穷级数、空间解析几何及相关几何应用、多元积分学及其应用。
- 线性代数和概率论在确定各自主讲义目录后再纳入完整地图。

### 英语一

- 语法与长难句以 2027 田静《句句真研》英语一目录为知识地图：简单句 → 长难句的构成 → 长难句的分析方法。
- 真题承担阅读、翻译、完形和新题型训练；写作讲义承担写作体系。
- 长期逐步建立词汇、句法、阅读、翻译和写作能力地图，不能只维护语法地图。

### 408

- 数据结构以王道《2027 数据结构》目录为知识地图：绪论、线性表、栈队列和数组、串、树与二叉树、图、查找、排序。
- 组成原理、操作系统和计算机网络后续分别按对应的 2027 王道复习指导目录推进。

## 四、角色分工

用户负责选择和阅读资料、标记疑问、先表达自己的理解、完成例题和章节题，并如实反馈用时、正确率、卡点和状态。

GPT 负责掌握目录和知识地图，定位当前节点，结合大纲、真题和目标分数控制节奏，把章节拆成每日单元；在用户预习后追问、纠错和深化，分析错题并依据证据更新地图、状态和未来安排。

GPT 不脱离主讲义安排大量无来源细节；用户也不随兴趣任意跳转而切断知识主线。

## 五、单个知识单元的标准流程

### 1. 定位

先明确科目、章节、小节、体系位置、前置知识、本次范围、第一轮目标和预计时间。

### 2. 自主阅读

用户通常阅读主讲义 10～30 分钟。目标是认识核心术语、看懂定义和例题结构、标出不理解处并形成问题，不要求一次完全学会。

### 3. 定向回补前置知识

只补当前问题必需的高中数学、基础英语语法或程序设计知识，解决后立即回到当前章节，不展开成另一条完整学习线。

### 4. 对话教学

用户先说明自己的理解、已懂和未懂部分、例题思路及具体疑问。GPT 再判断属于概念、前置知识、推导、方法选择、题意识别、计算或边界条件问题。

```text
用户表达理解
→ GPT 追问和检查
→ 只处理当前缺口
→ 用户重新解释或尝试
→ 确认理解
```

默认不长篇灌输，也不立即公布完整答案。

### 5. 课程补充

仅在讲义连续阅读两次仍无法理解、GPT 讲解后仍缺少直观认识、需要成熟推导或题型总结，或用户明确需要观察老师组织方式时，定向观看当前知识点对应片段。

### 6. 题目验证

使用讲义例题、章节基础题、典型题和必要的同类迁移题，检查定义理解、题型识别、方法选择、独立步骤和适用条件。

### 7. 错题分析

错误统一检查：知识不会、概念混淆、前置缺失、思路错误、方法选择错误、计算错误、审题错误、边界遗漏或畏难过早放弃。

```text
分析根源
→ 回到知识节点
→ 定向补充
→ 独立重做
→ 完成一道同类题
```

### 8. 更新进度

只依据实际输出和题目证据更新当前章节位置、知识点、掌握等级、未解决问题、复测安排和下一节点。

## 六、三张地图

每科长期维护以下三个视角，并随真实学习逐点补充，不提前创建空地图：

- **知识地图**：章节、小节、核心概念、前置知识、后续应用和节点联系。
- **考试地图**：考试范围、常见题型、题目形式、频率、第一轮要求和投入价值。
- **能力地图**：解释概念、识别题型、选择方法、独立计算或推演、识别边界和综合迁移的实际表现。

高频、重点和偏点的证据优先级为：

```text
正式考试大纲和近十年真题
＞ 主流成熟资料的共同判断
＞ 权威教材
＞ GPT 分析
```

无法确认时标记“暂定”，不得凭印象虚构频率。

## 七、掌握等级

| 等级 | 可观察标准 | 后续动作 |
|---|---|---|
| A：已掌握 | 能独立解释，完成基础题和常规题，说明适用条件，间隔复测仍能完成 | 正常复测 |
| B：基本掌握 | 概念基本清楚，基础题大部分能做，复杂条件下仍会犹豫 | 安排复测，稳定后推进 |
| C：初步理解 | 阅读或听讲能理解，独立做题仍不会 | 安排回补，不作为已掌握 |
| D：未掌握 | 核心概念不清，不能说明考点 | 重新学习或回补前置知识，不直接跳过 |

只有 A 或经过题目与间隔复测支持的稳定 B 才允许正常推进。掌握等级不能由计划、目录、看完、听懂或单次做对推断。

## 八、每日计划格式

每日任务必须包含：

1. 当前地图位置；
2. 当天讲义范围；
3. 自主阅读目标；
4. 需要回答的问题或主动输出；
5. 对应练习范围和训练量；
6. 完成标准；
7. 预计时间；
8. 最低完成线。

具体页码必须来自实际版本；无法确认时写章节或小节，不虚构页码。

## 九、阶段、周与每日计划

- 阶段计划确定科目、章节、时间范围和阶段验收。
- 周计划确定本周章节、各科时间和复测节点。
- 每日计划依据主讲义进度、实际掌握、错题反馈和当天可用时间动态生成。
- 阶段或周计划不得预先固定每日任务；每日任务只根据当时状态动态生成，也不机械补齐延期内容。

## 十、学科差异

- **数学一**：讲义概念和推导 → 对话理解 → 例题复现 → 基础题训练 → 题型识别；保留纸笔计算和完整推导。
- **英语一**：讲义学习词汇或句法 → 真题句子验证 → 结构分析 → 自然翻译 → 阅读或表达迁移。
- **408**：复习指导阅读 → 准确定义 → 机制和数据变化推演 → 选择题边界判断 → 算法题或计算题验证；工程经验不能替代教材定义和 408 标准。

## 十一、畏难与任务失控

犯困、回避、没有思路或任务过大时，立即缩小为一个可验证任务：阅读一个定义 → 用自己的话解释 → 完成一道最基础的题。

探索超出当前考研范围时，先判断是否属于必要前置、是否值得当前投入，以及掌握到什么程度即可返回主线。

## 十二、执行优先级

从本规范生效起，所有科目统一执行：

```text
主讲义目录建立知识地图
→ 定位当前章节和目标
→ 用户主动阅读并定向回补前置
→ 用户带着理解和问题进入对话
→ GPT 检查、讲解和深化
→ 必要时定向观看课程
→ 完成章节基础题并分析错题
→ 更新知识、考试和能力视角
→ 安排下一节点与间隔复测
```

后续计划不得采用“随机出题作为主要入口”“按视频顺序推进”“只用题目暴露缺口”“GPT 单方面制定每日计划”或“把听懂、看完视为掌握”等执行方式，并始终以本规范和最新学习记录为准。
