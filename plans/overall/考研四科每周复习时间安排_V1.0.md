# 考研四科每周复习时间安排 V1.0

> 适用阶段：2026年7月—2026年12月第一轮基础复习（三科执行口径）
> 目标院校：电子科技大学计算机专业硕士  
> 目标总分：350分以上  
> 时间条件：工作日每天最多5小时，周末每天最多6小时；408可利用上班碎片时间学习

---

## 一、时间分配原则

每周可用总时间：

- 工作日：5小时 × 5天 = 25小时
- 周末：6小时 × 2天 = 12小时
- 每周上限：37小时，其中三科核心任务约35小时，最多保留2小时用于补课、复盘或机动调整

第一轮复习阶段的时间分配如下：

| 科目 | 每周时间 | 占比 | 当前任务 |
|---|---:|---:|---|
| 数学一 | 16小时 | 45.7%（核心时间） | 建立概念体系，完成基础题和中档题训练 |
| 英语一 | 9小时 | 25.7%（核心时间） | 词汇语境、长难句、阅读和表达同步积累 |
| 408 | 10小时 | 28.6%（核心时间） | 利用上班时间推进知识学习，周末完成练习和复盘 |
| 机动与补课 | 最多2小时 | — | 用于延期补课、复盘或状态调整，不安排政治 |
| **核心任务合计** | **35小时** | **—** | — |

当前阶段的优先顺序：

**数学一 → 英语一 → 408**

其中，408主要占用上班碎片时间，避免大量挤压下班后的数学和英语学习时间。

## 三、工作日执行顺序

工作日建议按照以下顺序执行：

**上班碎片时间完成408 → 下班后优先学习数学一 → 完成英语积累 → 剩余时间用于机动或补课**

### 1. 408：上班碎片时间

每天1.5小时可以拆分为3个30分钟时段：

1. 30分钟：观看课程或阅读教材；
2. 30分钟：合上资料，回忆概念、流程和关键结论；
3. 30分钟：完成选择题、整理笔记或复习错题。

每日完成标准：

- 新知识日：掌握1个小节或1个完整考点；
- 练习日：完成10～15道选择题；
- 复习日：能够脱离资料讲清本周主要概念和执行过程。

408按照以下顺序推进：

**数据结构 → 计算机组成原理 → 操作系统 → 计算机网络**

同一阶段集中学习一门，不在一天内频繁切换四门课程。

### 2. 数学一：下班后的第一学习时段

数学基础相对薄弱，数学一必须使用精力最集中的时间。

#### 新课日

学习流程：

**概念理解 → 公式或定理推导 → 典型例题 → 8～12道基础题 → 简短复盘**

完成标准：

- 能用自己的话解释核心概念；
- 能说明公式或方法的使用条件；
- 能独立完成大部分基础题；
- 记录仍然没有思路的题型。

#### 练习日

学习流程：

**知识回忆 → 15～20道基础或中档题 → 对答案 → 分析错因**

练习重点：

- 不追求偏题和怪题；
- 优先提高基础题和中档题的稳定正确率；
- 错题必须区分知识不会、思路错误、方法选择错误和计算错误。

### 3. 英语一：每天不断档

英语是一门长期积累型科目，每天至少完成一次有效输入和一次主动输出。

不同日期分别安排：

- 词汇语境：在真题句子或例句中理解词义；
- 长难句：提取主干，分析从句和修饰关系；
- 阅读精读：定位依据，分析正确选项和干扰项；
- 翻译：先分析结构，再组织自然中文；
- 朗读复述：朗读句子或段落，并尝试口头改述；
- 写作或口语：主动使用本周积累的词汇和句型。

禁止将大量时间用于孤立背单词。词汇学习必须进入句子、阅读、翻译或表达活动。

### 4. 政治：本轮暂不安排

当前第一轮不安排政治学习时间。

后续重新纳入时再安排以下内容：

- 了解各科目组成和章节关系；
- 理解马原等基础概念；
- 区分理解内容、记忆内容和后期背诵内容；
- 暂不安排大量分析题背诵。

## 四、周末执行方式

### 周六：推进新内容

周六以推进新章节为主：

- 数学一：完成一个相对完整的知识模块；
- 英语一：精读1篇真题阅读或完成同等训练；
- 408：完成本周章节习题；
- 机动时间：补做延期任务或整理本周记录。

### 周日：检测与复盘

周日以检测掌握程度为主：

- 数学一：完成一次章节小测，整理重要错题；
- 408：完成一次选择题测试，回顾错误知识点；
- 英语一：完成阅读训练，并进行写作或口头表达；
- 汇总本周完成情况，制定下一周任务。

周日复盘只回答以下四个问题：

1. 本周真正掌握了哪些内容？
2. 哪些任务只是看过，但不能独立完成？
3. 哪类错误重复出现？
4. 下周需要增加、减少或调整什么？

## 五、每日最低完成线

当工作较忙、状态较差或出现畏难情绪时，不取消整天学习，执行最低完成线：

| 科目 | 最低完成任务 |
|---|---|
| 数学一 | 学习20分钟，并独立完成2道基础题 |
| 英语一 | 精读1个长难句，并复习10～20个语境词汇 |
| 408 | 学习1个小考点，完成5道选择题 |
| 机动 | 根据实际延期情况补做三科任务 |

启动后状态恢复，可以继续完成原计划；状态仍差，完成最低任务后结束，避免因任务过重形成连续逃避。

---

## 六、时间不足时的调整规则

当实际学习时间低于计划时，按照以下顺序保留任务：

1. 保留数学一的核心学习时间；
2. 保留英语一的每日最低积累；
3. 将408的新课改为复习或少量选择题；
4. 机动时间不得默认转为政治学习；如需调整科目范围，应先更新 `STATUS.md`。

不得通过连续熬夜补回所有欠缺时间。未完成任务应重新排入下一周，而不是机械追赶已经失效的计划。

当上班时间无法学习408时：

**减少当日408任务 → 周五和周末补充 → 不挤占数学一主学习时段**

---

## 七、每周调整标准

每周结束后，根据实际结果调整下一周计划：

| 情况 | 调整方式 |
|---|---|
| 数学课程听懂但题目不会做 | 减少听课时间，增加基础题训练 |
| 数学连续出现无思路 | 回补前置知识，降低单次任务难度 |
| 英语背过单词但阅读仍看不懂 | 增加长难句和语境分析，减少孤立背词 |
| 408看课较多但选择题错误率高 | 增加回忆和做题时间，减少被动观看 |
| 机动时间不足 | 优先处理延期的三科核心任务，不新增政治内容 |
| 多科任务持续无法完成 | 降低单周章节数量，不降低每日学习连续性 |

---

## 八、当前阶段执行重点

2026年7月至12月的核心任务是完成第一轮基础复习，不追求一次性掌握所有难题。

阶段要求：

- 数学一：完成主要章节第一轮学习，基础题能够独立完成；
- 英语一：形成每日词汇、长难句和阅读训练习惯；
- 408：完成四门课程的基础知识学习和章节选择题；
- 政治：本轮暂不安排。

总原则：

**工作碎片时间推进408 → 晚间黄金时间主攻数学 → 英语每日积累 → 机动补课与周末复盘**
